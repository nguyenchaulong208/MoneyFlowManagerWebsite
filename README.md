# Dòng Tiền

Website quản lý tài chính cá nhân bằng HTML, CSS và JavaScript thuần.

## Chạy website

Yêu cầu Node.js 18 trở lên:

```powershell
npm start
```

Mở `http://localhost:3000`.

## Kiểm tra JavaScript

```powershell
npm run check
```

## Dữ liệu

Giao dịch, tài sản và khoản nợ được lưu trong `localStorage` của trình duyệt. Có thể sao lưu và khôi phục dữ liệu bằng tệp JSON trong phần **Cài đặt**.
